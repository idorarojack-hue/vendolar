# Vindolar roadmap

Vindolar is built on Deriv's open-source `trading-bot-template`. The goal is a full trading-tools platform
(bot builder plus a set of manual, analysis and automation tools), similar in scope to other Deriv
partner sites, but with Vindolar's own design, names, wording and bots.

## Principles

- **Own design and content.** Don't copy other sites' logos, artwork, text or bot files.
- **Honest names.** Don't call something "AI" unless it is. Digit statistics are "statistics";
  martingale is "martingale".
- **Risk controls are mandatory** in every automated tool: stake, take profit, stop loss, a maximum
  stake cap and a visible Stop button. Martingale is off by default and always capped.
- **Demo first.** Automated tools start on the demo account; real-money use needs an explicit confirmation.
- **Statistics describe the past only.** Volatility indices are generated by a random number generator,
  so past digits do not predict the next one. Every analysis screen says so.

## Architecture

| Piece | Where | Notes |
|---|---|---|
| Market data (ticks, digits, public quotes) | `src/services/vindolar/market-data.ts` | Its own read-only WebSocket to Deriv's public endpoint, so analysis screens can watch many markets without touching the bot's connection. |
| Trading (quotes, buy, sell, open contracts) | `src/services/vindolar/trading.ts` | Uses the logged-in connection `api_base.api`. When logged in, quotes also come from it so displayed payouts match what trades pay. |
| Auto-trade engine | `src/services/vindolar/auto-trader.ts` | One engine per tool with mandatory TP/SL, hard stop-loss cap, capped martingale, real-money confirmation. Lives outside React so sessions keep running across tabs. |
| Rules & strategies | `rules.ts`, `digit-strategies.ts`, `indicators.ts` in `src/services/vindolar/` | Pure, unit-tested entry rules used by the automated pages. |
| Bots for the Bot Builder | `src/services/vindolar/bot-loader.ts` | Builds real bots from the bundled Quick Strategy templates (used by Free Bots and Quick Bot). |
| Shared UI | `src/components/vindolar/` | Session panel (settings, Start/Stop, stats, trade log), number field, market/contract pickers, shared styles. |
| Pages | `src/pages/<tool>/` | One tab each. Tab order, ids and url hashes live in `NAV_TABS` in `src/constants/bot-contents.ts`. |

## Floating Scanner

Bottom-right on every tab. Ranks all 13 markets by how far recent ticks are from fair odds (σ) and runs
5,000-tick quick tests of any strategy. It never claims to predict: |σ| > 2 happens ~1 in 20 by chance.

## Deriv API coverage (reviewed against developers.deriv.com)

| Area | Endpoints | Status |
|---|---|---|
| Market data | active_symbols, ticks_history (max 2,000 per request — measured), ticks, contracts_for | Used |
| Trading | proposal, buy, sell, proposal_open_contract | Used |
| Account | statement, profit_table | Used (Reports) |
| Account | portfolio | Not used yet (could restore open positions after a reload) |
| Trading | contract_update, cancel, bulk purchase | Not needed now |
| Automation | auto_list_strategies (Martingale, D'Alembert, both require TP/SL), auto_start/stop | Possible later: server-side bots |
| Copy trading | copy_start / copytrading_list | Not in the new API (UnknownMethod) |
| Limits | 360 trading calls/min per connection | Buys paced at ≤ 300/min in `buyContract` |

## Measured results (Strategy Tester, 20,000 ticks, flat stake, public payouts 1.95)

| Strategy | Market | Win rate | Break-even | Return |
|---|---|---|---|---|
| Midline Split | V100 (1s) | 50.8% | 51.3% | −0.86% |
| Always Even | V100 (1s) | 49.9% | 51.3% | −2.76% |
| Trend Rider | V100 (1s) | 51.9% | 51.3% | +1.13% (z = 0.5, luck) |
| Trend Rider | V75 | 49.7% | 51.3% | −3.13% |
| Trend Rider | V25 (1s) | 51.2% | 51.3% | −0.13% |

No strategy beats break-even consistently — consistent with random ticks and payouts below fair odds.
